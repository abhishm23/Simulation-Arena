# Simulation Arena — Autonomous Agent Market & Simulation Testbed

Full-stack agent simulation and stress-testing environment built with Python (FastAPI/DuckDB) backend and Node.js frontend.

## Overview
Simulation Arena orchestrates and visualizes multi-agent synthetic market scenarios, simulated stress workloads, and behavioral simulations.

## Tech Stack
- **Backend**: Python 3.11, FastAPI, DuckDB analytical data store (`backend/`)
- **Frontend**: Node.js, Web UI dashboard (`frontend/`)
- **Tools & QA**: Automation scripts and QA test deliverables (`tools/`)

## Quick Start
```bash
START.bat
# Or launch dev mode
START-dev.bat
```
